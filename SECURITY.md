## Security Threats
In the event of unintended access to the files in this repository academic plagarism is a possible outcome, as well as adversarial commitments to the repository and 
attempts to inject into the Gradescrope server.

## Security Steps Taken
No additional steps are necessary to secure this repository since the number of individuals who could benefit from stealing data (homework questions) from this 
repository is so few, and they have very little incentive to do so since the homework only takes on average <30 minutes. Additionally, Gradescope has sufficient 
security measures implemented to prevent injecton of malicious code via commiting files from this repository to their server.
